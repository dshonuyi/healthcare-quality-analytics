# CMS Care Compare source files

Download each file from the CMS Provider Data Catalog (Hospitals topic,
https://data.cms.gov/provider-data/topics/hospitals) and save it here with these names:

| Save as | Dataset |
|---|---|
| `hospital_general_information.csv` | Hospital General Information |
| `unplanned_hospital_visits.csv` | Unplanned Hospital Visits - Hospital |
| `hcahps_hospital.csv` | Patient survey (HCAHPS) - Hospital |

The files are public. They are not committed because the HCAHPS file exceeds GitHub's 100 MB limit.
The analysis in this repo used the release downloaded October 2026 (readmission period July 2023-June 2025;
HCAHPS period October 2024-September 2025).
