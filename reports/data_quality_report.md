## Findings and actions

- **U3 - Same patient, same vital sign, same timestamp recorded more than once** [Info] (2 records, 0.00%). Keep one value per timestamp so 'most recent reading' logic is deterministic.
- **T2a - Administrative 'Death Certification' encounter after date of death** [Info] (360 records, 0.20%). Expected: paperwork filed 1-14 days after death. Exclude from utilization counts; no correction needed.
- **C1 - Systolic BP outside 50-300 mmHg** [Critical] (5 records, 0.01%). Exclude from CBP numerator and send back to the clinic for correction.
- **C3 - Diastolic reading >= systolic reading at the same visit** [Critical] (70 records, 0.15%). Likely transposed values; flag for chart review.
- **C4 - HbA1c outside the 4-18 % assay reportable range** [Critical] (11,888 records, 48.88%). Values below 4% are not reportable by standard assays; in production this pattern usually means an interface or mapping error. Excluded from GSD; send to lab interface team.

## Notes

- Synthea data is generated by simulation, so it is much cleaner than a production EHR. The rules are written for production data; `tests/test_validation.py` injects known errors into a small fixture and confirms 16 rules catch exactly the planted errors while 4 others raise no false positives.
- The same rule set can be scheduled to run on every refresh, with results trended over time as a data-quality scorecard for the clinical effectiveness team.
